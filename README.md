**KostLife - Sistem Manajemen Keuangan Anak Kos Berbasis Web**

**Tujuan Sistem:**
KostLife bertujuan untuk membantu anak kos dalam mengelola kebutuhan sehari-hari secara terorganisir melalui satu sistem. Sistem ini dapat digunakan untuk mencatat pemasukan dan pengeluaran, memantau tagihan beserta tanggal jatuh temponya, mengatur jadwal aktivitas rutin, serta memberikan informasi mengenai kondisi keuangan pengguna sehingga pengguna dapat melakukan pengelolaan kebutuhan dengan lebih baik.

**Ruang Lingkup:**
Ruang lingkup sistem KostLife meliputi:
- Dashboard, untuk menampilkan ringkasan kondisi keuangan, pengeluaran, tagihan, dan jadwal pengguna.
- Keuangan, untuk mencatat pemasukan dan pengeluaran serta menampilkan ringkasan atau statistik pengeluaran.
- Tagihan, untuk mencatat jenis tagihan, nominal, tanggal jatuh tempo, dan status pembayaran.
- Jadwal, untuk mencatat aktivitas rutin seperti pembayaran kos, laundry, bersih-bersih, atau kebutuhan lainnya.
- Sistem ditujukan untuk pengguna individu, khususnya mahasiswa atau pekerja yang tinggal di kos.
- Sistem berfokus pada pencatatan dan pengelolaan kebutuhan pribadi, bukan sebagai sistem pembayaran atau layanan transaksi secara langsung.
